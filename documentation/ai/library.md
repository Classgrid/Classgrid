The **Library** keeps your files in one place. Its page says: *"Manage your uploaded and AI-generated files."* Anything you upload in a chat, and files the AI makes for you, such as PDFs and spreadsheets, can be found here later without scrolling back through old chats.

## What you'll find in the Library

| Kind of file | Examples |
|---|---|
| **Files you uploaded** | PDFs, Word and PowerPoint files, spreadsheets, CSV and text files, photos, audio and video you added to a chat |
| **Files the AI made** | PDFs, Word, Excel and PowerPoint files and other files the agent created for you. Images you create are in the AI Hub under **Images** (see [Images](/docs/images)) |

For the file types the AI can read, see [Files and documents](/docs/files-and-documents).

## Open the Library

Open the **Library** page in Classgrid AI to see your files.

## Find a file

The Library has a few tools to help you find what you need fast.

### Search

Use the search box to find a file by what you remember about it, such as a word from its name.

### Filter by date

Use the date filter to show only files from a certain time, for example the files from last week's project.

### Sort

Change the sort order to see your files in the order that suits you.

<callout type="info">

Tip: give your uploads clear names before you add them, like `client-proposal-march.pdf`. It makes search in the Library much easier later.

</callout>

## Storage meter

The Library shows a **storage meter** so you can see how much space your files are using. Keep an eye on it if you upload a lot of large files such as videos.

## Use a Library file in a new chat

You don't need to upload the same file twice. From the message box in Agent mode:

1. Type **@** in the message box to open the menu.
2. Choose **Add from library** (*"Browse and search your files"*).
3. Search for the file and pick it.
4. Ask your question, for example *"Summarise this PDF in five bullet points."*

The file is added to your message, and the AI can read it like a fresh upload.

## Common uses

- Keep all your reports in one place and pull any of them into a new chat to make a summary.
- Reuse last month's spreadsheet of sales to make a new chart or report.
- Find the PDF report the AI made last week and ask for a new version.
- Pick up a client proposal PDF from an earlier chat and ask for an updated draft.
