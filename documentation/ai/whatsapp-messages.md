Classgrid AI uses WhatsApp to send you login codes, results, files and reminders. You can also message it while a task is running. This page explains what WhatsApp messages can and can't do.

<callout type="warning">Texting the Classgrid AI WhatsApp number does not start a new task. New tasks start from a WhatsApp call or from an email to agent@classgrid.in.</callout>

## The help bot and your login code

If you message **+91 81492 77038** when no task is running, the help bot answers. It helps you get set up, for example by guiding you through verifying your number.

When you first message Classgrid on WhatsApp, the help bot replies with steps like these:

1. Go back to the **Verify WhatsApp** screen on chat.classgrid.in.
2. Choose your country code (India: +91) and enter your WhatsApp number.
3. Tap **Send OTP**.
4. Your 6-digit code arrives in the same WhatsApp chat within a few seconds.

The code is valid for 10 minutes. If it doesn't arrive, you can ask for a new one after 60 seconds. See [Verify your WhatsApp](/docs/verify-whatsapp) for the full steps.

## Messages while a task is running

Once a task is running (for example after a [WhatsApp call](/docs/whatsapp-calls)), your WhatsApp messages go to that task:

- Send extra details, like "Make it two pages, not one."
- Send photos or PDFs the agent needs.
- It replies "got it" and passes them to the running task.

Some long tasks also stop and wait for your answer on WhatsApp, for example "Which of these three designs do you like?" When you reply, the task carries on. See [Long tasks](/docs/long-tasks).

## Getting results on WhatsApp

The agent can send things to your verified WhatsApp:

| What | How it arrives |
|---|---|
| Answers and updates | As normal WhatsApp messages |
| Finished tasks | The result plus a link to the chat, ending with "✅ Task completed." |
| PDFs | As real PDF files you can open and forward |
| Images, audio and video | As real files |

You can ask for this in any AI chat, for example:

- "Make a one page summary of this PDF and send it to my WhatsApp."
- "When the report is ready, send it to me on WhatsApp."

## Reminders on WhatsApp

You can ask the AI to remind you on WhatsApp, as well as by email. For example:

- "Remind me on WhatsApp every weekday at 7 am to plan my day."
- "Send me a WhatsApp reminder on Friday at 5 pm to submit the report."

Reminders can be one time, daily, weekly or on chosen weekdays, for up to 90 days.

<callout type="info">A reminder sends the message that was written when you set it up. The AI does not run again at that time, so a reminder can't give you fresh news or new numbers each day.</callout>

There is a limit on how many WhatsApp messages the AI can send you each week. See [Schedules and reminders](/docs/schedules-and-reminders).

## What WhatsApp can't do

- **Start a new task by text.** Call instead, or email agent@classgrid.in.
- **Message other people.** Results and reminders go only to your own verified WhatsApp.
- **Work from an unverified number.** Verify your number on chat.classgrid.in first.

## Common questions

<details><summary>I sent a text and only got a help message. Why?</summary>No task was running, so the help bot answered. To start a task, make a WhatsApp call to +91 81492 77038 or email agent@classgrid.in.</details>

<details><summary>Can the AI send WhatsApp messages to my customers?</summary>Not from the Classgrid number. If you have your own WhatsApp Business account, you can connect it with the WhatsApp Business plugin. See the Plugins page.</details>

<details><summary>Can I get the result on WhatsApp when I started the task on the website?</summary>Yes. Ask the agent to send the result to your WhatsApp when it is done.</details>
