Classgrid AI can answer with many different AI models. Most people leave it on **Auto**, which picks a good model for each message. If you want more control, you can pick a model yourself and change it for any message.

## Auto (the default)

The model picker starts on **Auto** — "Picks the best model for each message". Auto is the easiest choice: you do not need to know which model is best at what. Use it unless you have a reason to pick something else.

## Which one should I pick?

There is no single right answer. These are simple starting points:

| You want… | Try |
|---|---|
| "Just make it work" | **Auto** |
| A quick answer or short rewrite | **Claude Haiku 5.5** or a **Flash** model |
| A long report, research brief or careful analysis | **Claude Sonnet 5.5** or **Claude Opus 5.5** |
| Help with code | **Claude Sonnet 5.5**, **Claude Opus 5.5** or **Kimi K2.7 Code** |
| To compare how different models answer | Ask the same question, switch model, and ask again |

<callout type="info">

Whichever model you choose, the agent still has its tools: web search, files, the code sandbox, images, PDFs, plugins and more. The model changes how it thinks and writes, not what it can reach.

</callout>

## How to switch models

1. In the message box, open the model picker (it shows **Auto** by default).
2. Pick a model from the list, or open **More models**.
3. Send your message. That message is answered by the model you picked.

### Switching in the middle of a chat

You can switch model for any message, even halfway through a conversation. The new model sees the same chat, so you do not need to repeat yourself. A common pattern is to draft with a fast model, then switch to a stronger one for the final, careful version.

## FAQ

<details>
<summary>Does Auto always use the same model?</summary>

No. Auto picks the best model for each message, so it can change from one message to the next.

</details>

<details>
<summary>Which model answers my WhatsApp calls?</summary>

Calls are answered by a fast voice setup chosen by Classgrid, not by the model picker. The work you ask for is then done by the full agent. See [WhatsApp calls](/docs/whatsapp-calls).

</details>

<details>
<summary>Can I set a default tone or style for every model?</summary>

Yes. Use [Skills and custom instructions](/docs/skills-and-custom-instructions) in the AI Hub to tell the AI how you like answers. These apply whichever model you pick.

</details>
