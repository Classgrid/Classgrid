Agent mode is the home screen of [chat.classgrid.in](https://chat.classgrid.in). It is an AI agent, not just a chatbot: it can search the web, read your files, run code, make files and images, publish websites, send email, use your connected apps and keep working in the background. You ask in plain words, and it picks the right tools.

## The message box

The box says "Ask anything, analyse a file, or schedule a task…". Around it you will find:

| Control | What it does |
|---|---|
| Paperclip (**Attach file**) | Upload files from your computer. |
| Sliders icon (**AI Hub**) | Open plugins, skills, settings and **Upgrade**. |
| **Dictate** (mic) | Speak, and your words are typed into the box. |
| Model picker | Choose **Auto** or a specific model. See [Choose a model](/docs/choose-a-model). |

### The @ menu

Type `@` in the box to open a quick menu:

- **Add photos & files** — "Upload from computer"
- **Add from library** — "Browse and search your files" (see [Library](/docs/library))
- **Create image** — "Visualize anything" (see [Images](/docs/images))
- **Web search** — "Find real-time news and info" (see [Web research](/docs/web-research))
- The **plugins**, such as Gmail, Notion or GitHub (see [Plugins](/docs/plugins))

## What the agent can do

| Capability | What it means | Learn more |
|---|---|---|
| **Web search** | Finds current news and facts, with numbered **[n]** citations. It can also open and read any link you give it. | [Web research](/docs/web-research) |
| **Read files** | PDF, Word, PowerPoint, Excel, CSV, text, images, audio and video. Up to 6 files per message. | [Files and documents](/docs/files-and-documents) |
| **Create images** | Makes a picture from your description. | [Images](/docs/images) |
| **Code and data** | Writes and runs Python, JavaScript or shell code in a safe sandbox. Cleans data, draws charts, and makes Word, PowerPoint, Excel and PDF files. | [Code and data](/docs/code-and-data) |
| **Publish a website** | Builds a site and puts it live at `yourname.sites.classgrid.in`. | [Publish a website](/docs/publish-a-website) |
| **Rich answers** | Charts, diagrams, flashcards, quizzes, planners, countdowns, weather, maps and more. | [Answer cards](/docs/answer-cards) |
| **Plugins** | Works with apps like Gmail, Google Calendar, Drive, Notion, Slack, GitHub and Vercel. | [Plugins](/docs/plugins) |
| **Email** | Sends email with attachments from agent@classgrid.in. You can also email it a task. | [Email the agent](/docs/email-the-agent) |
| **Reminders** | One-time, daily, weekly or chosen weekdays, by email and WhatsApp. | [Schedules and reminders](/docs/schedules-and-reminders) |
| **Long tasks** | Keeps working after you close the tab, for up to 48 hours. | [Long tasks](/docs/long-tasks) |
| **WhatsApp delivery** | Sends results and real files to your verified WhatsApp. | [WhatsApp messages](/docs/whatsapp-messages) |

## How a task runs

1. You send a request.
2. The agent decides which tools it needs and shows each step as it works (for example searching, reading a file or running code).
3. It replies with text, files, links or [answer cards](/docs/answer-cards).
4. You can follow up, ask for changes or tap a suggested next question.

<callout type="info">

You do not need special commands. Just say what you want, for example "Turn this PDF into clear notes" or "Build a landing page for my bakery". The agent works out the steps.

</callout>

## Ideas to try

- "Turn a PDF into clear notes." / "Create a quiz from a PDF."
- "Make me a 2-week plan for my product launch, with a countdown."
- "Clean up messy spreadsheet data." then "Draw a chart from your data."
- "Write meeting notes and action items." / "Draft a project proposal."
- "Research a topic with real sources." / "Plan content for the whole week."
- "Build me a simple, modern one-page personal portfolio website."
- "Summarise a YouTube video for you." / "Turn a voice note into text."
- "Write SQL queries from plain English." / "Debug an error in your code."

## Make it yours

- **Skills and custom instructions** — set tone, length, format and emoji use, tell the AI about yourself, or add your own skills. Saying "remember…" or "from now on…" makes the AI save it as a skill. See [Skills and custom instructions](/docs/skills-and-custom-instructions).
- **Incognito chat** — "Incognito chats are not saved to your history or search." Closing the chat deletes it. See [Incognito](/docs/incognito).
- **Library** — "Manage your uploaded and AI-generated files." See [Library](/docs/library).

## Agent mode or Project Mode?

| Use Agent mode for… | Use Project Mode for… |
|---|---|
| Questions, research, files, images, documents, reminders | Working on a GitHub code repository |
| Quick websites hosted at `sites.classgrid.in` | Changes saved as pull requests you review |
| Plugins, email and WhatsApp | A full code editor with a terminal |

A chat can be moved into a project with **Move to project**. See [Project Mode](/docs/project-mode).

## FAQ

<details>
<summary>Does the agent keep working if I close the tab?</summary>

Yes, for long tasks. It can keep going for up to 48 hours, wait for a set time or your WhatsApp reply, then carry on. See [Long tasks](/docs/long-tasks).

</details>

<details>
<summary>Can I share a chat with others?</summary>

Yes. Share a read-only link, or use **Share Grid** to chat with the AI together, up to 4 people in total counting you. See [Share links](/docs/share-links) and [Share Grid](/docs/share-grid).

</details>

<details>
<summary>Does using the agent cost anything?</summary>

Classgrid AI is free to start. Using the AI uses credits, and you can top up from **Upgrade** in the AI Hub. See [Credits and top-ups](/docs/credits-and-top-ups).

</details>
