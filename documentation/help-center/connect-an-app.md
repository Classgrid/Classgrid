Plugins connect Classgrid AI to the apps you already use, like Gmail, Google Calendar, Google Drive, Notion, Slack, GitHub and Vercel. Once connected, just ask the agent to work in them.

## Steps

1. Sign in at [chat.classgrid.in](https://chat.classgrid.in).
2. In the message box, click the sliders icon (**AI Hub**).
3. Open the **Plugins** tab (**Plugins & Integrations**).
4. Tap the app you want, for example **Gmail** or **Notion**.
5. Tap **Connect**.
6. Sign in to that app and allow Classgrid AI to use it.
7. When you come back, the app shows as connected.

![AI Hub, Plugins, showing the list of apps to connect](SCREENSHOT:ai-hub-plugins)

## Use it in chat

Just ask in plain words:

- "Read my unread emails from today."
- "What's on my calendar for tomorrow?"
- "Search my Notion for recent strategy docs."

To point the agent at one app, type `@` in the message box. The menu lists your tools and **every plugin**. Pick the app, then type your request.

Each plugin also has a **Try asking the AI** list you can tap.

## The agent works as you

The agent uses **your** account in each app. An email sent with Gmail comes from your Gmail address. A Slack message is posted as you. So ask for a draft first: "Draft the email and show me before sending."

## Good to know

- Each plugin does a set list of things. For example, **Google Calendar** can list and create events but can't move or cancel them, and **Vercel** can deploy but can't roll back or show build logs. See [Plugins](/docs/plugins) for the full list.
- The **WhatsApp Business** plugin needs your own Meta app details, and sends from your business number, not the Classgrid number.
- The agent can use your connected apps during a [WhatsApp call](/help-center/article/call-classgrid-ai-on-whatsapp) too.
- For Project Mode, GitHub is connected separately. See [Connect GitHub and install the app](/help-center/article/connect-github-and-install-the-app).
