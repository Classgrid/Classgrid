The **Library** keeps your files in one place: "Manage your uploaded and AI-generated files." You don't have to scroll back through old chats to find them.

## What's in the Library

- **Files you uploaded** in a chat: PDFs, Word, PowerPoint, spreadsheets, CSV, text, photos, audio and video.
- **Files the AI made for you:** PDFs, Word, Excel, PowerPoint and other files.

Images you create are **not** here. Find them in the **AI Hub** under **Images**. See [Create images](/help-center/article/create-images).

## Find a file

1. Open the **Library** page.
2. Type a word you remember from the file's name in the search box.
3. Use the date filter to show only files from a certain time.
4. Change the sort order if you like.

![The Library page with search, date filter, sort and the storage meter](SCREENSHOT:library)

## Use a Library file in a new chat

1. Type `@` in the message box.
2. Choose **Add from library** ("Browse and search your files").
3. Search for the file and pick it.
4. Ask your question, for example "Summarise this PDF in five bullet points."

The AI reads it just like a fresh upload.

## Check your storage

The Library shows a **storage meter**, so you can see how much space your files use. Keep an eye on it if you upload a lot of large files, such as videos.

## Tips

- Give files clear names before you upload, like `client-proposal-march.pdf`. It makes search much easier.
- Reuse last month's spreadsheet to make a new chart, instead of uploading it again.

## If it doesn't work

- **Can't find an image?** Look in AI Hub, **Images**.
- **Can't find a file from an Incognito chat?** Incognito chats are deleted when you close them, so copy or download anything you need first.
