You can delete any AI chat you no longer need.

## Delete a chat

1. At [chat.classgrid.in](https://chat.classgrid.in), find the chat in your chat history in the sidebar.
2. Open the chat's menu.
3. Choose **Delete**.
4. Confirm with **Delete chat**.

The chat is removed from your history.

## A chat someone shared with you

If someone invited you to a chat with **Share Grid**, the menu shows **Leave chat** instead of **Delete**.

1. Open the chat's menu.
2. Choose **Leave chat**.

The chat is removed from your list, but it stays with the other people in it. If the owner leaves, the next member becomes the owner, so the chat keeps going.

## An Incognito chat

You don't need to delete an Incognito chat. Closing it deletes it, and it can't be brought back. See [Use Incognito chats](/help-center/article/use-incognito-chats).

## Before you delete

- **Copy anything you need.** Copy answers you want to keep.
- **Download your files.** Save any files from the chat you still need. Your uploaded and AI-made files are also listed in your [Library](/help-center/article/find-files-in-library).

## Project Mode projects

Deleting a project in Project Mode doesn't delete your code: "Its code stays on GitHub. Only the project here is deleted." To delete the code, delete the repo on GitHub.

## If it doesn't work

- **No Delete option?** It may be a shared chat. Use **Leave chat**.
- Still stuck? Contact us from the [support page](/support).
