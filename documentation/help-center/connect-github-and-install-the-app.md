Project Mode works on top of GitHub. You connect your GitHub account once, then install the Classgrid GitHub app on the repos you want to work on.

## Step 1: Connect GitHub

1. Switch to Project Mode (**Switch Mode** → **Project**).
2. You'll see **Connect GitHub to use Project Mode**. Click **Connect GitHub**.
3. Sign in to GitHub and allow access.
4. You come back to the **Projects** page, which shows your GitHub picture, name and email.

## Step 2: Install the Classgrid app

1. On the Projects page, find the card **Install the Classgrid app**.
2. Click **Install app**.
3. On GitHub, choose the account or organisation and the repos to allow, then confirm.
4. You're sent back to Classgrid and see **"Classgrid app installed"**.

The app is what lets Project Mode download your code and open pull requests. It must be installed on each repo you work on.

## Step 3: Create a project and link a repo

1. Click **New project**.
2. Optional: click **Add logo** to add a logo.
3. Type a **Project name** and click **Create**.
4. In **Link a GitHub repo**, pick a repo. Private repos work too and are tagged **private**.

### No repo yet?

Click **Enter project without a repo** to start empty. Later, click **Ask Agent to create repo** in the editor banner and the agent makes one for you. Repos it creates are **private by default**. You can ask "Make this repo public" any time.

## If it doesn't work

- **You see "Reconnect GitHub"?** The link to GitHub stopped working. Click **Reconnect GitHub** and sign in again.
- **Banner says "Install the Classgrid app on {repo}"?** Click **Install Classgrid app** and allow that repo on GitHub.
- **Repo not in the list?** Make sure the Classgrid app is allowed on that repo in GitHub.
- **Need a different branch?** Projects always open the latest code on the default branch.

Full details: [Connect GitHub](/docs/connect-github).
