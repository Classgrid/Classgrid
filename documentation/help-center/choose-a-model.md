Classgrid AI can answer with many AI models. Most people leave it on **Auto**, which "Picks the best model for each message". You can pick a model yourself any time.

## Steps

1. In the message box, open the model picker. It shows **Auto** by default.
2. Pick a model from the list, or open **More models** to see the rest.
3. Send your message. That message is answered by the model you picked.

![The model picker open, showing Auto and the model list](SCREENSHOT:model-picker)

## Which one should I pick?

| You want… | Try |
|---|---|
| "Just make it work" | **Auto** |
| A quick answer or a short rewrite | **Claude Haiku 5.5** or a **Flash** model |
| A long report or careful analysis | **Claude Sonnet 5.5** or **Claude Opus 5.5** |
| Help with code | **Claude Sonnet 5.5**, **Claude Opus 5.5** or **Kimi K2.7 Code** |

**Claude Fable 5.1** is a premium model. If it isn't available on your account, **Claude Opus 5.5** is a good choice for hard work.

## Switch in the middle of a chat

You can change the model for any message. The new model sees the same chat, so you don't need to repeat yourself. A handy pattern: draft with a fast model, then switch to a stronger one for the final version.

## Good to know

- Every model can still use the agent's tools, like web search, files, code, images and plugins. The model changes how it thinks and writes, not what it can reach.
- Stronger models and longer chats use more credits. See [Credits and top-ups](/help-center/article/credits-and-top-ups).
- WhatsApp calls don't use the model picker. Classgrid chooses a fast voice setup for calls.
- To set a tone or style for every model, see [Teach Classgrid AI about you](/help-center/article/teach-classgrid-ai-about-you).
