Studio Mode is a full agentic workspace: the agent browses, codes and runs commands for you. You chat on the left, and a pane on the right shows it working in a live browser, your files and a terminal.

## Switch to Studio Mode

1. Sign in at [chat.classgrid.in](https://chat.classgrid.in).
2. Click your name at the top of the sidebar.
3. Under **Switch Mode**, choose **Studio**.

## Pick a project (optional)

To work on code, pick a project:

1. On a new chat, click the project button above the chat box (it says **No project** at first).
2. Choose a project, or click **New project**.
3. Wait for *"Getting [name] ready…"* to finish.

You need GitHub connected to open a project. If Studio says *"GitHub is not connected"*, click **Go to Project Mode** and set it up there. See [Connect GitHub and install the app](/help-center/article/connect-github-and-install-the-app).

To only use the browser, you don't need a project.

## Ask the agent

Type in the chat, for example:

- "Open our website and check every page for broken links."
- "Start the dev server and test the sign-up form."
- "Add a contact page and show it to me in the browser."

Click **Show pane** at the top right to see the tabs. The pane opens by itself when the agent uses the browser.

## Good to know

- Projects are shared with Project Mode. Switching between Project and Studio keeps your chat.
- You can't edit files yourself in Studio. Ask the agent, or click **Open** to continue in Project Mode.
- The agent asks before risky steps. See [Allow or block an AI action](/help-center/article/allow-or-block-an-ai-action).
