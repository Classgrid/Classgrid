You don't need to open the app to give Classgrid AI a job. Email it, and the agent works on it in the background.

## Steps

1. Open your normal email app.
2. Write to **agent@classgrid.in** from the **same email address you use to sign in** to Classgrid AI.
3. Say what you want in plain words. Attach any files the agent needs.
4. Send it.

The inbox is checked about every 45 seconds. You get a short automatic reply, and the agent starts working.

## Good emails to send

- "Turn the attached PDF into a one-page summary with the key points."
- "Draft a one-page project proposal for a bakery website and send it back as a PDF."
- "Clean up the attached spreadsheet and make a chart of monthly sales."

## Where to find the work

A task started by email is created as a project in **Project Mode**, so you can find its chat there. Tasks run for up to **48 hours**.

## Add more to a running task

Send another email from your account email. It adds to the task that is already running, instead of starting over. You can also send extra details on WhatsApp while the task runs.

## Let the agent send emails for you

In any Agent mode chat, ask the agent to send an email. It sends from **agent@classgrid.in** and can attach files:

- "Make this report a PDF and email it to priya@example.com."
- "Email me the meeting notes with the slides attached."

Want the email to come from your own Gmail or Outlook? [Connect that app](/help-center/article/connect-an-app) first and ask the agent to use it.

## If it doesn't work

- **Nothing happened?** Check that you sent the email from the address on your Classgrid AI account. Emails from any other address are not linked to you.
- **Out of credits?** Email tasks use credits. See [Out of credits](/help-center/article/out-of-credits).

Full details: [Email the agent](/docs/email-the-agent).
