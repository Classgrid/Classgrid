Classgrid AI is an agent, not just a chatbot. You ask in plain words, and it picks the right tools, such as web search, reading files or running code.

## Steps

1. Open [chat.classgrid.in](https://chat.classgrid.in) and sign in.
2. Click in the message box ("Ask anything, analyse a file, or schedule a task…").
3. Type what you want and press Enter.
4. Watch the steps appear as the agent works. It may search the web, open pages, run code or build files before it answers.
5. Read the answer. Ask a follow-up, ask for changes, or tap a suggested next question.

## Good first things to try

- "Search the web for this week's top AI news and give me 5 points with sources."
- "Make me a 7-day plan for a family trip to Jaipur, with a day-by-day schedule and a rough budget."
- "Build me a simple, modern one-page personal portfolio website."

You don't need special commands. Just say what you want.

## Prefer to talk?

Click **Dictate** (the mic) in the message box and speak. Your words are typed into the box so you can check them before you send.

## Tips for better answers

- **Be specific.** "List every deadline in this PDF and who owns it" works better than "summarise".
- **Keep one topic per chat.** Start a new chat for a new topic.
- **Check the sources** when facts matter. Web answers show numbered **[n]** citations.

## Want a private chat?

Use an **Incognito chat**. It is not saved to your history. See [Use Incognito chats](/help-center/article/use-incognito-chats).

## If it doesn't work

- If the agent stops because you are out of credits, see [Out of credits](/help-center/article/out-of-credits).
- If the page seems stuck, reload it and send your message again.

Learn more in [Agent mode](/docs/agent-mode).
