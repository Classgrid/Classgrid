In Studio Mode, you can point the agent at a file in your project without typing its path.

## Drag a file in

1. Open the **Files** tab in the pane.
2. Find the file in the tree, or open it so it has a tab.
3. Drag the file (or its tab) onto the chat box.
4. It shows as a small chip with the file name. Click the **X** to remove it.
5. Type your message, for example "Make this page work on phones", and send.

## Good to know

- Folders can't be dragged, only files.
- You can add more than one file.
- File names in the agent's answers are chips too. Click one to open that file in the Files tab, at the right line.

Full details: [Studio tabs](/docs/studio-tabs).
