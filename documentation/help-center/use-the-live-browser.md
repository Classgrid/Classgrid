The **Browser** tab in Studio Mode is a real browser in the cloud that you and the agent share.

## Let the agent use it

Ask in the chat, for example:

- "Open example.com and summarise the home page."
- "Find the cheapest flight from Pune to Delhi next Friday on these two sites."
- "Check that the checkout button works on our store."

You'll see the agent's blue pointer, with labels like **Agent · Clicking** or **Typing**, and the note *"The agent is using the browser"*. While it works, the browser is locked for you.

## Use it yourself

When the agent isn't working:

1. Type a website or a search in the address bar and press **Enter**.
2. Click, scroll and type right on the page.
3. Use **Back**, **Forward** and **Reload** like a normal browser.

## Sign in to a website

The agent never types passwords or one-time codes. When a site needs you to sign in:

1. Click into the login box in the Browser tab.
2. Type your email and password yourself.
3. Tell the agent to carry on.

Your sign-ins are remembered for your next Studio chats.

## Save a screenshot

- **Save a screenshot** (camera) downloads what you see now.
- **Full page screenshot** saves the whole page in the **Screenshots** tab.

## Good to know

- The browser stays open after the agent is done.
- Each chat remembers its own last page.
- After about 30 minutes with nobody using it, the browser shuts down. It opens where you left off next time.

If it doesn't start, see [The Studio browser isn't working](/help-center/article/studio-browser-not-working).
