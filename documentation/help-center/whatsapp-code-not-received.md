If your 6-digit code doesn't arrive on WhatsApp, the fix is usually quick.

## Send Hi to the Classgrid number on WhatsApp first

This is the most common reason. WhatsApp can only deliver your code after you have messaged Classgrid.

1. Open WhatsApp on your phone.
2. Send **Hi** to **+91 81492 77038**.
3. Wait for the help bot's reply: "✅ Done! Your WhatsApp is now ready to receive your login code."
4. Go back to the **Verify WhatsApp** screen on chat.classgrid.in.
5. Tap **Send OTP** again.

The code arrives in that same WhatsApp chat within a few seconds.

## Check these next

1. **Country code.** Make sure you picked the right one (India: **+91**).
2. **Number.** Check that you typed your WhatsApp number correctly, with no extra digits.
3. **Right chat.** Look in your WhatsApp chat with +91 81492 77038, not in your SMS messages.
4. **Wait before you ask again.** You can ask for a new code after **60 seconds**.
5. **Phone online.** Make sure your phone has internet so WhatsApp can receive messages.

## The code arrived but doesn't work

- The code works for **10 minutes**. If it's older, tap **Send OTP** for a new one.
- If you asked for more than one code, use the **newest** one.
- Type all 6 digits with no spaces.

## Make sure you're using the right number

The only Classgrid AI number is **+91 81492 77038**. Save it as a contact, for example "Classgrid AI", so it's easy to find.

Contact us from the [support page](/support). Tell us your country code and the email on your Classgrid AI account.
