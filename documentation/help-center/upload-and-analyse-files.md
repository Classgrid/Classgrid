Classgrid AI can read PDFs, Word, PowerPoint, Excel, CSV, text files, images, audio and video. You can attach up to **6 files** to one message.

## Upload from your computer

1. Click the paperclip (**Attach file**) in the message box. Or type `@` and pick **Add photos & files**.
2. Choose up to 6 files.
3. Type what you want, for example "Turn this PDF into clear notes", and send.

![The @ menu showing Add photos & files and Add from library](SCREENSHOT:attach-menu)

## Reuse a file you uploaded before

1. Type `@` in the message box.
2. Pick **Add from library** ("Browse and search your files").
3. Search for the file and pick it.
4. Ask your question.

## What you can ask

| Goal | Try asking |
|---|---|
| Notes | "Turn this PDF into clear notes." |
| Short summary | "Summarise this 40-page report in one page." |
| Compare | "Compare these two contracts and list the differences." |
| Data | "Clean up this spreadsheet and show totals by month as a chart." |
| Meetings | "Turn this meeting recording into notes and action items." |
| A photo | "Copy the items and prices from this photo of a bill into a table." |
| A new file | "Make a PDF from these notes." |

For a YouTube video, just paste the link and ask for a summary.

## Tips

- **Point to the part you need**, like "only chapter 3" or "just the sheet called Sales".
- **Attach related files together** so the agent can compare them.
- **Keep asking.** The agent remembers the files in the chat, so you don't need to upload again.
- **Check important numbers.** For money or dates, ask it to quote the exact line or cell it used.

## If it doesn't work

- **More than 6 files?** Send the rest in your next message.
- **Photo is hard to read?** Use a clear, well-lit photo or scan.
- **File is in Google Drive or Notion?** Connect that app first. See [Connect an app](/help-center/article/connect-an-app).
