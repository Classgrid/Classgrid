Verifying your WhatsApp number takes about a minute. It lets you call Classgrid AI on WhatsApp, get results and files there, and get reminders on WhatsApp.

## Before you start

- Sign in at [chat.classgrid.in](https://chat.classgrid.in).
- Keep your phone with WhatsApp nearby.
- Save **+91 81492 77038** as a contact, for example "Classgrid AI". This is the only Classgrid AI number.

## Steps

1. On WhatsApp, send **Hi** to **+91 81492 77038**. The help bot replies that your WhatsApp is ready to receive your login code.
2. Go back to the **Verify WhatsApp** screen on chat.classgrid.in.
3. Choose your country code (India: **+91**) and enter your WhatsApp number.
4. Tap **Send OTP**.
5. A 6-digit code arrives in the same WhatsApp chat within a few seconds.
6. Type the code on the **Verify WhatsApp** screen. Your number is now verified.

![The Verify WhatsApp screen with the country code and number fields](SCREENSHOT:profile-whatsapp)

The code works for **10 minutes**. If it doesn't come, you can ask for a new one after **60 seconds**.

## Rules to know

- **One number, one account.** Calls only work from a number that is verified on exactly one Classgrid AI account.
- **WhatsApp calls only.** The AI answers WhatsApp voice calls, not normal phone calls.
- **Texting doesn't start a task.** A new task starts from a WhatsApp call, or from an email to agent@classgrid.in sent from your account email.

## If it doesn't work

- No code? See [WhatsApp code not received](/help-center/article/whatsapp-code-not-received).
- Code not accepted? It may be older than 10 minutes. Ask for a new one.
- Still stuck? Contact us from the [support page](/support).
